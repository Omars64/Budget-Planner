Original seasonal sticker atlas approved in the Seasonal worlds POC.

Created with the built-in OpenAI image-generation tool and a transparent-background pass. This WebP preserves the original dimensions and alpha. No watermarked reference artwork is bundled. Rain uses CSS highlights and trails.

Six Halloween characters, six autumn leaves, six snowflakes, three summer and three spring illustrations share one cached atlas. Crop coordinates live in src/lib/seasonalArt.js.
